# UX/UI Specification - LCB V1

Le site est mobile-first. En moins de dix secondes, un visiteur doit identifier LCB, comprendre que les commerçants sont prioritaires et accéder à WhatsApp ou à l'appel. La page d'accueil respecte l'ordre défini dans le SSOT, avec une section Épargne distincte et sobre après le focus commerçants.

Le header est compact avec logo, navigation essentielle, WhatsApp et menu mobile. Les menus Solutions et Pour qui ? exposent un seul niveau de liens. Sur mobile, la barre d'actions expose WhatsApp et l'appel sans masquer le contenu.

À contrôler aux largeurs 360, 390, 430, 768, 1024, 1366 et 1920 px : absence d'overflow, CTA accessibles, image non déformée, focus visible, labels explicites, erreurs compréhensibles et zones tactiles confortables.
