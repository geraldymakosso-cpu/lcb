# CONTENT & BRAND GUIDELINES — LCB

# 1. Marque

**LCB — La Congolaise Business**

Descripteur :

**Cabinet de gestion et d'accompagnement**

---

# 2. Personnalité de marque

La marque doit être :

- proche ;
- professionnelle ;
- accessible ;
- rassurante ;
- dynamique ;
- locale ;
- pragmatique.

Elle ne doit pas paraître :

- luxueuse artificiellement ;
- élitiste ;
- bureaucratique ;
- agressive ;
- trop institutionnelle ;
- pseudo-bancaire.

---

# 3. Ton rédactionnel

Écrire :

- avec des phrases courtes ;
- avec un vocabulaire simple ;
- en français accessible ;
- orienté vers les besoins concrets ;
- avec des CTA directs.

---

# 4. Message principal

> **Un commerçant, une solution de financement.**

---

# 5. Message institutionnel

> LCB accompagne les commerçants, entrepreneurs et porteurs de projets avec des solutions de gestion, d'accompagnement et de financement adaptées à leurs besoins.

---

# 6. Variantes commerciales

### Commerçants

> Faites avancer votre activité.

### Entrepreneurs

> Donnez à votre projet les moyens d'avancer.

### Accompagnement

> Un conseiller à vos côtés pour mieux structurer votre besoin.

| Compte courant | Non validé |

| Acceptation garantie | Interdit éditorialement |

# 9. Couleurs

Couleurs officielles :

- Vert
- Jaune
- Rouge

## Usage recommandé

### Vert

Couleur dominante.

Utilisation :

- CTA principal ;
- éléments de confiance ;
- titres secondaires ;
- éléments graphiques.

### Jaune

Accent.

Utilisation :

- badges ;
- éléments de mise en avant ;
- détails visuels.

### Rouge

Accent secondaire.

Utilisation modérée :

- petits détails ;
- identité nationale ;
- éléments graphiques secondaires.

### Blanc / neutres

Doivent constituer la majorité des arrière-plans.
